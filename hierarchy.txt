Key Points (C++98):
•	Station is an abstract base class with at least one pure virtual function (calculatePricePerMin).
•	Derived classes override calculatePricePerMin and displayInfo for runtime polymorphism.
•	All classes use encapsulation (private data members, public getters/setters).
•	File handling methods (saveToFile, loadFromFile) are implemented in each class for persistence.

4. Main System / Manager Class (STL Heavy – Facade Pattern Style)
		Place Class Diagrams

+---------------------------+
|     EVChargingManager     |
+---------------------------+
| - stations: std::map<std::string, Station*>   |
| - users: std::map<std::string, User*>         |
| - activeBookings: std::queue<Booking*>        |
| - completedSessions: std::vector<ChargingSession> |
| - logFileName: std::string                    |
+---------------------------+
| + loadAllData()                           |
| + saveAllData()                           |
| + addStation(Station*)                    |
| + addUser(User*)                          |
| + findAvailableStation(std::string type, double lat, double lon) : Station* |
| + bookSlot(std::string userID, std::string stationID, int minutes) : bool |
| + startCharging(std::string bookingID)    |
| + endCharging(std::string bookingID)      |
| + generateRevenueReport() const           |
| + findTopRevenueStations(int topN) : std::vector<Station*> |
| + recommendStationsForUser(std::string userID) |
| + backupSystem(const std::string& backupFile) |
| + restoreSystem(const std::string& backupFile) |
+---------------------------+
STL Usage (C++98 compliant):
•	std::map<std::string, Station*> → fast lookup by ID
•	std::map<std::string, User*> → user management
•	std::queue<Booking*> → FIFO for active bookings
•	std::vector<ChargingSession> → completed sessions (with std::sort, std::find_if, std::accumulate for analytics)
•	Algorithms: std::sort, std::find_if, std::for_each, std::remove_if
